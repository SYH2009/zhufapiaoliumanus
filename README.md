# 竹筏漂流 / Ocean Raft Drift

> 一个全屏、持续运动的第一人称程序化海洋竹筏漂流体验。海面、竹筏、天空和环境叙事全部由代码实时生成。

**Ocean Raft Drift** 是一个以 Three.js WebGPU、TSL 与原生 ES Modules 实现的浏览器图形实验。体验将观察点固定在竹筏甲板上方：长涌、交叉风浪和微表面细节共同推动竹筏的起伏、横摇与纵摇；航图式边缘仪表保留控制能力，而不打断开放水域的画面。

## 特性

| 模块 | 实现概要 |
|---|---|
| 程序化海面 | 五组分层 Gerstner 波、群波包络、解析切线法线，以及多尺度 FBM 微表面。 |
| 海面光照 | 深浅水色、Fresnel 反射、稀疏浪尖泡沫、受噪声门控的太阳镜面闪光与昼夜连续调色。 |
| 真实受波 | 竹筏从四个水线角实时采样波面；阻尼浮力、惯性漂移与姿态平滑共同驱动上下起伏、横摇和纵摇。 |
| 程序化环境 | 解析天空、太阳圆盘与低云带；远岛、海鸟、星光、船灯、局部尾流和涟漪均由代码生成。 |
| 运行保护 | WebGPU 优先、TSL/WebGL2 兼容回退、DPR 上限、帧率保护、标签页暂停与响应式触控操作。 |

## 技术栈

项目使用 **Three.js** 的 `WebGPURenderer` 与 **TSL** 节点材质实现波面位移和着色。浏览器支持 WebGPU 时会启用节点 Bloom 与 ACES Filmic 色调映射；没有可用适配器时，体验会以 TSL/WebGL2 兼容后端继续运行。

运行时不依赖外部贴图、模型、HDRI、视频、字体或远程内容服务。除 Three.js 外，视觉内容均由着色器和程序化几何生成。

## 本地运行

需要 Node.js 22+ 与 pnpm。

```bash
pnpm install
pnpm dev
```

开发服务器启动后，打开终端显示的本地地址即可进入体验。可以使用以下命令进行验证和生产构建：

```bash
pnpm check
pnpm build
```

## 操作

| 控件 | 作用 |
|---|---|
| **SEA STATE** | 调整波浪幅度、浪尖泡沫、尾流和竹筏响应强度。 |
| **TIME OF DAY** | 改变日夜循环起点；天空和海面共享太阳方向与色温。 |
| **DRIFT SPEED** | 调整竹筏的惯性漂移和尾流节奏。 |
| **FRAME CAP** | 在 30–60 FPS 间设定上限；低帧时体验会自动降低渲染 DPR。 |
| **第一人称固定** | 开启时保持站立于筏上的视角；关闭后可鼠标或触控自由环视。 |

## 浏览器兼容性

建议使用支持硬件图形加速的 Chromium 浏览器。WebGPU 可提供完整的节点后期效果；其他现代浏览器会降级到兼容渲染路径，核心海面与交互仍可使用。
